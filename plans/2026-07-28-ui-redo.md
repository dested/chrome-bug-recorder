## The three laws

1. **The panel is five things**: Record, point-at-something, the timeline, Copy prompt, done.
   Anything else is either deleted, inside a collapsed `settings` row, or on the page.
2. **Zero keyboard anywhere.** No `<kbd>`, no shortcut copy, no "set one" links, no key relays as
   the *only* path. Every action is a labeled click. (Manifest commands stay wired for muscle
   memory but the UI never mentions them; the `hintline`, `editShortcut`, panel E/R/D/P relay,
   and every shortcut lookup DIE.)
3. **The controls live where the eyes are.** While recording, a floating toolbar sits ON THE PAGE:
   clock · draw/click toggle · clear · mark · stop. The panel HUD shrinks to status + Stop.

## Core plumbing (ALREADY LANDED — do not redo, just use)

- `Settings.drawStart: boolean`, default `true` — recording starts with ink armed.
- ContentCommand `recording` now carries `origin?: string` (scope for the toolbar) and
  `drawStart?: boolean`. Background sends them on start/stop and to late-loading tabs.
- New Request `{ type: 'recording:stop' }` — sent by the content toolbar; the PANEL hears it in its
  runtime listener (same pattern as `recording:event`) and calls its stopRecording; background
  answers `{ ok: true }`.

## A. Content script (`src/content/index.ts`, `src/content/ui.ts`)

**The recording toolbar.** When `{ type: 'recording', active: true, origin, drawStart }` arrives and
`origin` is empty or matches `location.origin`: show a bottom-center glass pill (existing `.glass`
language, shadow root, above everything):

```
[● 2:41] [✏ draw] [clear] [★ mark] [■ stop]
```

- `●` pulses (the one live animation). Clock ticks locally from the moment the toolbar arrived
  (drift vs the panel is acceptable and invisible at mm:ss granularity).
- `✏ draw` is a TOGGLE, **initially on iff `drawStart`**. On = the live ink canvas captures the
  pointer (drawing works immediately, scroll/clicks go to ink); the button shows the armed
  accent-soft treatment and the label flips to `→ click` so the way back is labeled, not inferred.
  Off = pointer goes to the page, ink stays visible.
- `clear` wipes strokes. `★ mark` sends `recording:mark` (existing). `■ stop` sends the new
  `recording:stop`. Every button ≥32px hit target, lowercase labels, no tooltips-as-crutch.
- The toolbar must never block the app irrecoverably: it's draggable horizontally OR (simpler,
  pick this) it fades to 0.35 opacity when the cursor is within 120px and isn't over it, back to 1
  on hover. It never captures clicks outside its own pill.
- Esc still exits draw-capture silently (kept, unadvertised). `c`-to-clear key stays as a silent
  bonus; the BUTTON is the real path. The `draw:toggle` command still works (silent).
- Teardown on `{ active: false }`: toolbar gone, ink gone, strokes cleared, ripples off.
- The old behavior (ink only via hotkey) is replaced: the ink canvas + toolbar are one unit now.
  Keep stroke-end → `recording:mark`, keep ripples (only when ink is NOT capturing).

**De-shortcut the capture overlay.** In the aim hint chip: mode buttons become plain lowercase word
buttons (`point · region · draw · page` — already clickable, drop the single-letter kbd styling),
and the `esc` chip becomes a `✕` button that calls the same cancel path. The composer keeps its
mic button and drain bar; remove any `<kbd>` visuals (ctrl+space title text can stay in `title`).
Voice phrases and silence-commit are untouched.

## B. Side panel (`src/sidepanel/App.tsx`, `styles.css`, preview harness)

Layout, top to bottom — NOTHING ELSE:

```
GRIPE ◎                                   2 parts · 3 notes · on disk
[gripe name, big inline input]            [history · 4]   ← only when other gripes exist
inbox line (see below)

┌────────────────────────────────────────────┐
│                 ●  Record                  │   ← the hero. Full width, tall (biggest
└────────────────────────────────────────────┘     control in the product), NOT accent-filled
        [ ⊙ point at something broken ]           ← the ONE secondary capture entry

timeline — parts + notes, chronological, cards as shipped today (keep the
           expand/edit/review interactions; hover-only ✕ stays)

settings ▸        ← one collapsed row, --faint; expands to the pill toggles:
                    auto-mic · auto-send · spotlight · stay armed · start drawing on
[ Copy prompt for Claude Code ]  [ done ]     ← footer. .zip appears ONLY when no
                                                folder is connected or FSA unsupported
```

- **Record button**: when recording → the HUD replaces it in place: pulsing dot, mm:ss (--fs-xl),
  `N frames · N lines · N marked`, the interim line, and ONE button: `■ Stop`. A single quiet line
  under it: `draw and stop from the little bar on the page` (only if the toolbar is enabled).
  No mark button here, no draw state, no hint stack — the page toolbar owns those.
- **point at something broken** arms element mode. Region/draw/page leave the panel entirely —
  they live in the on-page aim chip after arming. One entry point, power on the page.
- **Inbox line**: connected = `dot + inbox · <mono path>` and nothing else visible; the ✕ (forget)
  and `path` edit move behind a click on the line itself (expands to the detail row: full path
  input with the copy about why, `forget this folder`, Reconnect when perm needed). Not connected =
  a single card: `gripes need somewhere to land` + `[Choose folder]` + one --faint sub-line
  `pick or create one folder — every project's gripes go there`. Blocked-picker fallback keeps
  `Open in tab →`.
- **Reconnect** (permission lapsed): the line shows one accent-soft `reconnect` button. Nothing else.
- **Empty state** (no content): three --faint lines, no key names:
  `nothing yet` / `hit Record and talk through what's wrong,` / `or point at it and just say it`.
- **history**: replaces the chevron — a text button `history · N` (N = other sessions), opens the
  same session list (rows keep: name, meta, closed tag, hover ✕). Hidden when N = 0.
- Whisper/interrupted/review affordances on cards: keep exactly as shipped.
- Kill in App.tsx: `shortcut`/`markShortcut` state + `chrome.commands.getAll`, `editShortcut`,
  `hintline`, the E/R/D/P key relay effect (keep only Escape → disarm), all `<kbd>` in JSX.
- Add to the panel's runtime listener: `recording:stop` → `void stopRecording()`.
- The `settings:set` of `drawStart` reaches the recording toolbar live only on next recording —
  fine, don't plumb mid-recording updates.
- **styles.css**: this is a REDESIGN, not a reskin — delete dead classes (modes row, hintline,
  kbd), the hero gets real height (new tokens if needed, e.g. `--hero-h` stepping 52/60/68px),
  the secondary entry reads clearly smaller. Keep the ui.md laws: token scale only, accent = state
  only, no shadows, inverted primary, --max cap, breakpoints as-is.
- **Preview harness**: keep modes, make sure none of the seeds reference shortcuts; `nofolder`
  shows the setup card; add nothing new unless trivial.
